# 設定ファイルの配置方式の選択

ストア経由配置は読み取り専用であり、ツールや GUI による書き換えが失敗する。
また、編集のたびに `switch` が必要になる。
「ツールが書き換えない」ことは確認しきれず、実際に `.zprofile` は Codex のインストーラに追記されていた。
一方でストア経由配置の利点は、個人の dotfiles では小さい。
そのため、原則としてストア外配置にし、ツールが書き換えないと確認できていて編集頻度も低い設定だけをストア経由配置にする。

配置はディレクトリ直下のエントリ単位で行い、配置先のディレクトリ自体は symlink にしない。
`~/.config/nvim` には、リポジトリにないファイル（`_backup/` や worktree 向けの `after`）がある。
ディレクトリ単位で配置すると、`switch -b` でこれらがディレクトリごと退避されるためである。
