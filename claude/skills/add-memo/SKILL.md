# memos リポジトリにメモを追加する

対象リポジトリ: `~/development/suimenkathemove/memos`

- `memos/` : 技術トピック別のメモ本体（このスキルの主な追加先）
- `_shared/` : todo・タスク・プロンプトなど。技術メモではないものだけここへ
- `_local/` , `memos_private/` : 公開しない内容。機微な情報はこちらへ

迷ったら `memos/` 配下に置く。
