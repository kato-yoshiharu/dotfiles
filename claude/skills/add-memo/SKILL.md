# memos リポジトリにメモを追加する

対象リポジトリ: `~/development/suimenkathemove/memos`

- `memos/` : 技術トピック別のメモ本体（このスキルの主な追加先）。
  公開リポジトリにコミットされるので、公開してよい内容だけ。
- `memos_private/` : 非公開リポジトリの submodule。
  業務先の社名・案件名を含むメモなど、公開リポジトリに置けない内容はここへ。
- `_shared/` : todo・タスク・プロンプトなど、**技術メモではない作業用のもの**。
  グローバル gitignore に入っているためコミットされない。
- `_local/` : このマシンだけの一時ファイル・スクラッチ。
  同じくグローバル gitignore に入っておりコミットされない。

判断の順番:

1. 残す価値のある技術メモか → いいえ なら `_shared/`。
2. 公開リポジトリに置けない内容（案件の内容）を含むか →
   含むなら `memos_private/`、
   含まないなら `memos/`。迷ったらユーザーに確認する。
3. 消えても困らない一時ファイルだけ `_local/`。

`_shared/` と `_local/` はコミットされないので、**残したい知見をここに書かない**。

## 手順

1. 追加先を決める。
   - まず `ls memos/` と `grep -ril <キーワード> memos/` で**既存の該当メモを探す**。
   - 既存メモがあれば新規作成せず、そこに追記する（適切な見出しの下）。
