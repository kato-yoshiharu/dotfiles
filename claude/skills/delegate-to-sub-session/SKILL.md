# サブセッションへサブタスクを引き継ぐ

メインのセッションのコンテキストを汚さずに、サブタスクを切り分けたいときに使う手順。

## サブエージェントとの使い分け

サブエージェントとの違いは、**引き継ぎ先が対話型セッションで、確認プロンプトに人が答えられる**点。

|                                                   | 引き継ぎ先                   |
| ------------------------------------------------- | ---------------------------- |
| 調査・読み取り中心で、結果だけ欲しい              | サブエージェント（Agent）    |
| 実行の承認を人に挟みたい（例: `terraform apply`） | サブセッション（このスキル） |
| 途中経過を人が見て、随時介入する必要がある        | サブセッション（このスキル） |

## 引き継ぎの手順

引き継ぎ先は**タスクごとに新しく作る**。

1. `ListAgents` で**自分のセッション名**を確認する。
   出力の1行目に`This session is <名前>` として出る。
2. herdr 配下かどうかを判定する。`echo $HERDR_ENV` が `1` なら配下。
3. 配下なら、ペインを分割してその場でサブセッションを起動する
   （「herdr でペインを分割して起動する」を参照）。
   配下でなければ、ユーザーに新しいターミナルで `claude` を起動してもらう。
   起動したらフォーカスはそのペインに移る。
4. 完了報告が届いたら、ペインを閉じる。

### herdr でペインを分割して起動する

引き継ぎ内容は `claude` の引数として渡す。

内容はクォートを含む複数行なので、シェルに直接書かず、スクラッチパッドのファイル経由で渡す。

```bash
cat > <スクラッチパッド>/handoff.txt <<'EOF'
<引き継ぎ内容>
EOF
```
