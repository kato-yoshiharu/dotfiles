# サブセッションへ子タスクを引き継ぐ

メインのセッションのコンテキストを汚さずに、子タスクを切り分けたいときに使う手順。

## サブエージェントとの使い分け

サブエージェントと違い、**引き継ぎ先は対話型セッションなので確認プロンプトに人が答えられる**。
人の判断を挟みたい操作（例: `terraform apply` ）や、メインのセッションのコンテキストを消費したくない作業に向く。

|                                      | 引き継ぎ先                 |
| ------------------------------------ | -------------------------- |
| 調査・読み取り中心で、結果だけ欲しい | サブエージェント（Agent）  |
