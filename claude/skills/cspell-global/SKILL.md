# グローバル cspell 辞書に単語を追加する

対象ファイル: `~/development/suimenkathemove/dotfiles/cspell.json`

これは `install/install.sh` の `cspell link add` でグローバル設定として登録されている個人辞書。

プロジェクト固有の用語（そのリポジトリでしか使わない造語など）は、そこにプロジェクトローカルの
`cspell.json` があればそちらに追加するか、ユーザーにどちらへ入れるか確認する。

## 手順

1. 追加する単語を決める。
   ユーザーが明示していない場合は、cspell の出力や対象ファイルから未知語を集める。
   - `npx cspell <path>` または `npx cspell lint --words-only --unique <path>` で未知語一覧を取得できる。
2. `cspell.json` を Read し、Edit で `words` 配列の**正しい並び順の位置**に単語を挿入する。
3. 追加後に `npx cspell <path>` を再実行して、エラーが解消したことを確認する。

## ルール

- `words` は**大文字小文字を無視したアルファベット順**で並べる（既存の並びに合わせる）。
- 既存の単語（大文字小文字を無視して一致）は追加しない。
- 元の表記（例: `PKCE` のような大文字）はそのまま保持する。
- 配列の最後の要素にも**末尾カンマを付ける**既存スタイルを維持する。
- インデントは 2 スペース。

## 最後に、追加した単語の表を出力する

作業の最後に、今回 `words` に追加した単語を必ず次の形式の表で報告する。

| 語       | 使用箇所                    | 語が正しい根拠                                                                                     |
| -------- | --------------------------- | -------------------------------------------------------------------------------------------------- |
| deepcopy | nvim/lua/plugins/snacks.lua | [Neovim Lua ドキュメント](https://neovim.io/doc/user/lua.html) — `vim.deepcopy({expr})` の項に記載 |

表のルール:

- 1 行 1 語。追加した単語をすべて載せる。
- 「使用箇所」は、その単語を辞書に入れる必要が生じたリポジトリ相対パス。複数あるときは代表的な 1〜2 件。
- 「語が正しい根拠」は、その語が実在する正しい綴りであることを示す一次情報へのリンクと、ページ内のどこに出てくるかを書く。
  - 単語ごとに 1 つずつ Web 検索する。まとめて調べたことにしない。
  - 公式ドキュメント・公式リポジトリ・公式サイトを優先する。個人ブログや Stack Overflow は最後の手段。
  - リンクは Markdown リンクにし、ラベルはドキュメント名やページ名にする。
  - ページ内の位置は、見出し名・関数シグネチャ・オプション名・コマンド名など具体的に書く。「公式ドキュメントに記載」だけでは不十分。
  - 一次情報が見つからなかった語は「根拠が見つからなかった」と明記し、辞書に追加してよいかユーザーに確認する。
- 使用箇所が見つからない語は追加せず、削除した語として別表で理由とともに示す。
