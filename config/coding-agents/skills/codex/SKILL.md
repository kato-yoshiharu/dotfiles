# Codex CLI を呼び出す

Claude Codeのセッションから、Codex CLIをサブプロセスとして直接実行する。

## 手順

1. ユーザーの依頼内容（引数 ARGUMENTS）をもとに、Codexに渡す依頼文をClaude Codeが整える。
   目的・対象範囲・観点が伝わるように具体化し、依頼文の末尾には必ず次の一文を付け加える。

   ```text
   確認や質問は不要です。具体的な提案まで自主的に出力してください。
   ```

   これがないと、Codexが確認待ちで停止し進捗が止まることがある。

2. 対象ディレクトリは、特にユーザーからの指定がなければカレントの作業ディレクトリ（cwd）を使う。
   別のディレクトリを指定された場合はそちらを使う。

3. 組み立てた依頼文と対象ディレクトリをユーザーに提示し、これで実行してよいか最終確認する。
   修正の指示があれば依頼文に反映し、再度確認する。

4. 次の形でコマンドを実行する。標準出力・標準エラーはそのままユーザーに見えるようにする（バックグラウンド化しない）。

   ```sh
   codex exec --full-auto --sandbox read-only --cd [対象ディレクトリ] "[依頼文]"
   ```

## ルール

- `--sandbox read-only` を必ず付ける。ファイル変更やコマンド実行が必要そうな提案が出ても、Codexにその場で実行させない。
  実際に変更を加えるかどうかはユーザーと相談してから、Claude Code側で行う。
- 依頼内容が曖昧な場合はユーザーに確認する。
